# dsh-locale-ru

Russian localization plugin for **DeepSeek Harness** (Cordis runtime plugin, comprehensive core & third-party UI dictionaries, runtime injection, and automatic DOM translator).

## Features
- Complete UI translation for all DeepSeek Harness sections (Chat, Plan, Goals, Models, Settings, Permissions, Workspaces).
- Dictionaries for ecosystem plugins (Better Sidebar, Agent Teams, Modlens, DSH Market, Archive Manager, etc.).
- Real-time DOM translator for dynamic strings.
- Compatible with DeepSeek Harness plugin architecture.
